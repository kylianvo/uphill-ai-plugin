# Uphill AI for Claude

This plugin connects Claude to your Uphill AI training plan and coach. Claude can read your plan, log a session, estimate a race time, plan pacing and fuelling, suggest shoes, and pass your questions to your coach.

It needs an Uphill AI account.

## Install in Claude Code

```bash
claude plugin marketplace add kylianvo/uphill-ai-plugin
```

```bash
claude plugin install uphill-coach@uphill-ai
```

Then run `/mcp`, choose uphill, and sign in with your Uphill AI account.

## Other assistants

Claude on the web and desktop, ChatGPT and other assistants: see https://uphill-ai.io.vn/assistants.

## Rules of use

Do not use this connection to copy Uphill AI's content or to train a model on it.
